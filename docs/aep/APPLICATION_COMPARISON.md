## Comparison notes

- Both accessible apps use React 19, TypeScript, Vite, and application-specific CSS, but they do not import a common UI package. AssetIQ Notifications adds React Router and Lucide; LiftIQ uses state-based routing and a separate visual/component convention.
- LiftIQ's alarms are source-domain lifecycles. AssetIQ Notifications' threads are delivery/workflow records. The notification app explicitly states that acknowledging its thread does not alter the source alarm or equipment.
- `Product` in AssetIQ Notifications includes LiftIQ, TankIQ, FlowIQ, ReeferIQ, and CloudIQ. This supports a configurable product label in notification records; it is not evidence of the other product applications or their APIs.
- “Implemented” in this matrix describes what the prototype source renders or simulates. It does not imply production persistence, backend enforcement, live telemetry, real delivery, or operational readiness.
